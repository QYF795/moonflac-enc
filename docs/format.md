# FLAC 格式笔记（实现依据）

规范：RFC 9639（FLAC），参考实现 libFLAC，解码对照 moonflac。
位流全部 **MSB-first**；CRC 均为**非反射**算法。

## 文件结构

```
"fLaC" 魔数
元数据块序列（STREAMINFO 必须第一个且存在）
帧序列
```

v1 只写一个 STREAMINFO 块（`is_last=1`）。

## STREAMINFO（34 字节 = 272 位）

| 字段 | 位宽 | 说明 |
|------|------|------|
| min block size | 16 | v1 写满块大小 |
| max block size | 16 | 同上 |
| min frame size | 24 | 未知写 0 |
| max frame size | 24 | 未知写 0 |
| sample rate | 20 | 0 = 未知（v1 要求 1..=655350） |
| channels − 1 | 3 | v1 支持 1-8 |
| bits per sample − 1 | 5 | v1 支持 8/16/24/32 |
| total samples | 36 | 0 = 未知（v1 必填） |
| MD5 | 128 | 见下 |

## MD5 语义（RFC 9639 §8.4）

对**未编码** PCM 求 MD5：声道交织、每样本**小端**、符号扩展到
`ceil(bps/8)` 字节后紧凑打包。对 8/16/24/32 位输入，`ceil(bps/8) = bps/8`
且小端二补码表示即输入字节序——原始字节直接喂 MD5 即可（moonflac 的
打包方式已与 ffmpeg 交叉验证过，往返测试自动校验本实现）。

## 帧头

| 字段 | 位宽 | v1 取值 |
|------|------|---------|
| 同步码 | 14 | `0x3FFE`（11111111111110） |
| 保留 | 1 | 0 |
| 分块策略 | 1 | 0 = 固定分块 |
| 块大小码 | 4 | 表码，或 0111 = 16 位扩展 |
| 采样率码 | 4 | 0000 = 取自 STREAMINFO |
| 声道分配 | 4 | channels − 1 |
| 位深码 | 3 | 000 = 取自 STREAMINFO |
| 保留 | 1 | 0 |
| 帧号 | UTF-8 | 1-4 字节编码（同标准 UTF-8） |
| 块大小扩展 | 16（可选） | **块大小 − 1**（见坑 1） |

### 块大小表码

1=192, 2=576, 3=1152, 4=2304, 5=4608, 6=预留, 7=扩展(16 位, −1),
8=256, 9=512, 10=1024, 11=2048, 12=4096, 13=8192, 14=16384, 15=32768

## 帧体

```
帧头字节 + CRC-8（只覆盖帧头）→ 各声道子帧 → 零填充至字节边界
→ CRC-16（覆盖帧起始到填充处全部字节，MSB-first 附帧尾）
```

CRC-8：多项式 `0x07`，初值 0；CRC-16：多项式 `0x8005`
（CRC-16/BUYPASS，非反射），初值 0。校验向量：CRC-16(b"123456789")
= `0xFEE8`。

## 子帧（v1：VERBATIM）

```
1 位 0（填充）+ 6 位类型码 000001 + 1 位 wasted-bits 标志 0
+ len × bps 位原样本（有符号二补码，掩码到 bps 位）
```

类型码表：000000 CONSTANT，000001 VERBATIM，001xxx FIXED（xxx = 阶），
1xxxxx LPC。wasted-bits 标志为 1 时后续存 k−1（k 为每样本可右移的
浪费位数），子帧类型按右移后有效位深解释——M1 引入，语义细节见
spike-notes。

## 坑

1. **块大小扩展存 −1**：码 0111 的 16 位值为「块大小 − 1」
   （RFC 9639 §9.2.2），与采样率扩展 1100 相同。写原值会让解码端
   多读一个样本，子帧越界、后续帧错位（往返测试实测：Truncated/
   BadResidual）。
2. **UTF-8 帧号是标准 UTF-8**：1-4 字节、上限 0x1FFFFF，非别种编码。
3. **固定分块末帧**：帧头声明实际样本数（短块走 16 位扩展），
   STREAMINFO min/max 仍写满块大小；解码端按 total_samples 截断。
4. **Buffer::write_string 是 UTF-16**：魔数等字节串必须 `write_bytes`。
